TBOP ADMIN DOCUMENT SETUP
=========================

This site has NO member accounts and NO public sign-up.
Only admin accounts you create manually in Supabase can upload/delete documents.

ONE-TIME SETUP
1. In Supabase, open SQL Editor.
2. Open supabase-setup.sql from this website folder and run the entire file.
3. In Supabase: Authentication > Users > Add user.
   Create the officer/admin email and password. Turn on "Auto Confirm User" if shown.
4. Copy that user's UUID.
5. In SQL Editor run:
   insert into public.site_admins (user_id) values ('PASTE-UUID-HERE');
6. In Supabase Project Settings / API, copy:
   - Project URL
   - anon / publishable key (NOT service_role)
7. Open supabase-config.js and paste those two values.
8. Upload all website files to GitHub.

USING IT
- Go to admin.html
- Sign in with an approved admin account.
- Choose title, category and PDF.
- Click Upload & Publish.
- The PDF automatically appears on documents.html.
- Delete removes the uploaded PDF and its public listing.

ADDING ANOTHER ADMIN
1. Create them in Supabase Authentication > Users.
2. Copy their UUID.
3. Run:
   insert into public.site_admins (user_id) values ('THEIR-UUID');

REMOVING AN ADMIN
Run:
   delete from public.site_admins where user_id = 'THEIR-UUID';
Their login can still exist, but it immediately loses website admin privileges.

SECURITY
- Do not put a service_role key anywhere in this GitHub repository.
- The browser anon/publishable key is expected to be public.
- Row Level Security policies are what enforce admin-only uploads/deletes.
