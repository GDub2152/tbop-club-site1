THE BLOWTORCH OF PARMA - SIMPLE PUBLIC SITE

This is a separate static GitHub Pages-ready build. It does not change the existing tbop-club-site1 site.

Included:
- Home page and existing visual style
- Jim Snell W8DRZ memorial
- Public calendar
- Live NOAA solar data
- Membership information
- Official membership application PDF
- Public documents page
- News page

Removed:
- Portal Login
- Officer portal
- Admin dashboard
- Member account creation
- Private officer/member features

UPDATING EVENTS
Open script.js and add entries to EVENTS, for example:
{date:'2026-09-10', title:'Club Meeting'}

UPDATING NEWS
Open script.js and add entries to NEWS, for example:
{date:'September 10, 2026', title:'Meeting Update', body:'Our next meeting will be...'}

GITHUB PAGES
Upload the contents of this folder to a NEW repository. Do not overwrite tbop-club-site1. Enable Pages from the main branch/root.
