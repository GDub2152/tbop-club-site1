# TBOP 14.0.4 — Conditions Detail Viewer

This release changes the 14.0.3 expandable homepage cards back to the original
compact card layout.

Weather, Solar Conditions, and Band Conditions remain visible on the homepage.
Clicking any of the three opens a larger in-site detail window similar to the
News & Announcements reader. Visitors never leave the homepage/site.

No Supabase SQL migration is required.

Keep the existing live `config.js`; it is intentionally excluded.
